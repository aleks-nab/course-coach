# Course Coach

Личный трекер онлайн-курсов. Помогает принять одно решение: какой курс делать сегодня и какой маленький шаг сделать дальше.

Это один файл `index.html`. Ничего устанавливать не нужно.

## Как открыть

1. Скачай `index.html` к себе на компьютер или телефон.
2. Дважды щёлкни по файлу. Он откроется в браузере (Chrome, Edge, Firefox, Safari).
3. Лучше всегда открывать с одного и того же места, потому что данные хранятся в браузере и привязаны к адресу файла. Если переместить файл в другую папку, данные могут «не найтись». Тогда помогут Export и Import (см. ниже).

Чтобы открывать с телефона, можно выложить файл на GitHub Pages (бесплатно). Это можно сделать отдельно, когда захочешь.

## Как пользоваться

- **Today**: что делать сегодня, обратный отсчёт до ближайшего жёсткого дедлайна, мягкие напоминания, события и целевые даты на 30 дней. Подсказки необязательны, приложение ничего не переставляет само.
- **Active**: до 2 активных курсов. Попытка сделать активным третий мягко спросит, какой поставить на паузу.
- **Shelf**: таймлайн с датами до марта 2027 и курсы «на полке». Полка это нормально. Там же события.
- **Progress**: 4 карточки статистики, календарь занятий за 8 недель, история занятий, законченные курсы и сертификаты.
- **Log a session**: после занятия обнови, где остановилась, следующий шаг и прогресс. Минуты по желанию. При 100% приложение предложит отметить курс законченным и добавит +1 сертификат.
- Поля «Where I stopped» и «Next small step» на карточке можно править прямо там. Они сохраняются сами.
- Если чего-то не знаешь, оставляй пустым. Приложение покажет «not set» и ничего не придумает.

## Связь с чатом Claude

- **Copy summary for Claude**: копирует сводку на русском. Вставь её в чат, и Claude поможет спланировать неделю.
- **Export data (JSON)**: скачивает файл с копией всех данных (резервная копия).
- **Import data (JSON)**: вставь JSON текстом или выбери файл. Перед заменой приложение покажет, что изменится, и спросит подтверждение. Так чат может прислать обновлённые данные, а ты их загрузишь.

## Формат JSON

```json
{
  "version": 1,
  "courses": [
    {
      "id": "power-of-where",
      "title": "The Power of Where: Communicating with Maps",
      "org": "Esri MOOC",
      "url": null,
      "status": "active",
      "priority": null,
      "unit": "percent",
      "percent": 11,
      "done": null,
      "total": null,
      "info": "6 sections.",
      "stopped": "Section 1, Exercise 1 done.",
      "next": "Continue section 1.",
      "hardDeadline": "2026-12-09",
      "targetDate": "2026-12-01",
      "eventDate": null,
      "registered": null,
      "lastSession": "2026-11-03",
      "note": "",
      "finishedDate": null,
      "certificate": false
    }
  ],
  "sessions": [
    { "id": "s1", "courseId": "power-of-where", "title": "The Power of Where: Communicating with Maps", "date": "2026-11-03", "minutes": null }
  ]
}
```

### Поля курса

| Поле | Что это | Значения |
|---|---|---|
| `id` | уникальный короткий код | текст, без повторов |
| `title` | название | текст, обязательно |
| `org` | организация | текст или пусто |
| `url` | ссылка на курс | `https://...` или `null` |
| `status` | статус | `"active"`, `"shelf"`, `"event"`, `"finished"`, обязательно |
| `priority` | важность | `"important"`, `"low"` или `null` |
| `unit` | в чём считаем прогресс | `"percent"`, `"lessons"` или `null` |
| `percent` | процент, если `unit` = `percent` | число 0..100 или `null` |
| `done`, `total` | уроки, если `unit` = `lessons` | числа или `null` |
| `info` | заметка о курсе (сколько часов и т.п.) | текст |
| `stopped` | где остановилась | текст или пусто |
| `next` | следующий маленький шаг | текст или пусто |
| `hardDeadline` | жёсткий дедлайн (курс закрывается) | `"ГГГГ-ММ-ДД"` или `null` |
| `targetDate` | моя личная цель | `"ГГГГ-ММ-ДД"` или `null` |
| `eventDate` | дата события (для `status` = `event`) | `"ГГГГ-ММ-ДД"` или `null` |
| `registered` | зарегистрирована на событие | `true`, `false` или `null` (не указано) |
| `lastSession` | дата последнего занятия | `"ГГГГ-ММ-ДД"` или `null` |
| `note` | заметка | текст |
| `finishedDate` | когда закончен | `"ГГГГ-ММ-ДД"` или `null` |
| `certificate` | есть ли сертификат | `true` или `false` |

### Поля занятия (`sessions`)

| Поле | Что это |
|---|---|
| `id` | уникальный код занятия |
| `courseId` | `id` курса |
| `title` | название курса (на случай, если курс потом удалят) |
| `date` | `"ГГГГ-ММ-ДД"` |
| `minutes` | минуты или `null` |

### Правила

- Даты только в виде `ГГГГ-ММ-ДД`, например `2026-12-09`. В приложении они показываются как «9 Dec 2026».
- Активных курсов (`status` = `"active"`) не больше 2. Иначе импорт откажется и объяснит почему.
- Если значение неизвестно, ставь `null` или пустую строку. Не придумывай данные.
- Если в файле есть ошибка, приложение ничего не поменяет и покажет, что исправить.
- Количество сертификатов считается само: это курсы с `"certificate": true`.

## Для Claude в чате

Если тебя просят обновить данные: верни полный JSON выше (`version`, `courses`, `sessions`), с теми же `id` для существующих курсов. Меняй только то, о чём попросили. Ничего не выдумывай, неизвестное оставляй `null`.
